# DroxAI
DroxAI is a cybersecurity platform featuring SiteGuardian, a bot for monitoring and threat detection with unlimited scans across all pricing tiers. Hosted via Kansas Registered Agent.

## 🚀 Quick Start - Run It All

**Run the entire platform with one command:**

```bash
# Quick start (backend + bot engine)
./quick_start.sh

# Full platform (includes frontend)  
./run_all.sh
```

**Access the platform:**
- Backend API: http://localhost:8000
- API Documentation: http://localhost:8000/docs
- Health Check: http://localhost:8000/health

For detailed instructions, see [RUN_ALL_GUIDE.md](RUN_ALL_GUIDE.md)

## Directory Structure
- **backend/**: FastAPI backend.
- **frontend/**: React frontend.
- **static/**: Hugo site for GitHub Pages.

## Deployment
Deployed via Kansas Registered Agent for DNS and backend hosting.
